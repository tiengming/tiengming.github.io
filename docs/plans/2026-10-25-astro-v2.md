# 博客 v2（Astro 独立重建）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 用 Astro 7 + Tailwind 4 从零重建 tiengming.github.io，彻底摆脱 Gmeek 上游；保留「issue 写博文 → Action 触发部署」工作流，配置模块化、可被他人一键套用为模板；视觉上继承 aurora 血统并升级为「墨·玉·光」三层景深设计系统。

**Architecture:** 纯静态 Astro 站点（零前端运行时框架）。`scripts/sync-issues.mjs`（零依赖 Node 脚本）在 CI 中把仓库 open issues 全量镜像为 `content/posts/{N}.md`（frontmatter 携带元数据）；单一类型化配置 `src/config/site.ts` 驱动全站模块；CI 单工作流完成 同步→提交回存→构建（含 Pagefind 索引与旧链接重定向桩）→deploy-pages。

**Tech Stack:** Astro 7.4.x / @tailwindcss/vite 4.3.3 / Pagefind 1.5.2 / Node 22 / TypeScript / GitHub Actions（deploy-pages）。

**Spec:** 本文件 + `DESIGN.md`（设计事实源，Task 1 产出）。

## 需求拆解（双视角）

**开发工程师视角：**
- D1 去上游：删除 Gmeek 工作流/生成器/双份配置，代码全部自有。
- D2 内容管线：GitHub Issues 为唯一内容源；issue 增删改 → Action 全量镜像到 git 内 markdown；closed issue 不显示。
- D3 部署：单一 workflow，issues/push(main)/workflow_dispatch/schedule 触发，deploy-pages artifact 部署；构建产物不回存仓库。
- D4 模板化：他人 Use this template → 改一个配置文件 + 开 Pages 即上线。
- D5 性能：静态 HTML、岛屿架构、系统 CJK 字体（仅一款按 unicode-range 分包 webfont）、图片懒加载、prefers-reduced-motion 全量门控。
- D6 旧链接兼容：Gmeek 旧 URL 全部重定向到新 URL。

**UI 工程师视角（详见 DESIGN.md）：**
- U1 墨玉色系 + 楷体展示字 + 60-30-10。U2 强视角反馈（3D 倾斜 + 共享元素过渡）。U3 强动画（入场编排/滚动渐显/hover 三层阴影绽放；reduced-motion 门控）。U4 多层级 UI（极光层→内容面→卡片面→浮层）。U5 三段式 elevation 阴影。U6 禁 AI 味（deslop 清单 + 终审）。

## Global Constraints

- Node ≥ 22；astro 固定 7.4.1（本机 apt node 22.22.1 引擎上限）；tailwind 4.3.3；pagefind 1.5.2。
- 文章 URL 恒为 `/p/{issueNumber}/`；旧 URL 构建期生成 meta-refresh 桩页。
- 岛屿 JS gzip ≤ 30KB（除 Pagefind/utterances 懒加载资源）；不引入前端运行时框架。
- 字体仅 LXGW WenKai（分包）；正文系统 CJK；代码系统 mono。
- 一切动画门控 prefers-reduced-motion / pointer:fine / prefers-reduced-transparency。
- WCAG 2.2 AA；交互目标 ≥ 24px；焦点可见。
- zh-CN；个人数据仅允许出现于 src/config/site.ts、astro.config.mjs、public/CNAME。
- Git：每 Task 至少一提交；最终合并 main（本地，不推送）。

## Review Focus（失效模式 → 钉定）

1. 空正文 issue → 文章页仍渲染（T2 单测）
2. issue 关闭/删除 → 全量镜像清余（T2 单测）
3. 旧 URL 百分号编码精确复刻（T10 单测）
4. API 失败不触碰现有内容（T2 单测：先取全后落盘）
5. 触屏/弱动效 → tilt/渐显/极光降级（T4/T6 构建检查 + CSS 门控）
6. 模板化无个人数据泄漏（T12 grep 门禁）
